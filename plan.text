## STEP 4 — REDESIGN RULES FOR ALL COMPONENTS

Apply these rules when redesigning every file below.

### Color rules
- Remove ALL hardcoded Tailwind color classes: `bg-indigo-*`, `text-indigo-*`,
  `bg-blue-*`, `text-blue-*`, `bg-gray-*`, `text-gray-*`, `bg-white`, `text-white`,
  `bg-black`, `ring-indigo-*`, etc.
- Replace with semantic tokens: `bg-background`, `bg-background-secondary`,
  `bg-card`, `text-foreground`, `text-foreground-muted`, `text-foreground-subtle`,
  `border-border`, `border-border-strong`, `bg-primary`, `text-primary-foreground`
- For positive balances (owed to me): `text-success`
- For negative balances (I owe): `text-danger`
- For pending/warning states: `text-warning`

### Typography rules
- Headlines: `font-semibold tracking-tight` (not `font-bold`)
- Body: regular weight, `text-foreground-secondary`
- Labels/captions: `text-foreground-muted text-sm`
- Timestamps/metadata: `text-foreground-subtle text-xs`
- Remove all `tracking-tight` from body text

### Surface rules
- Cards: `bg-card border border-card-border rounded-2xl shadow-sm`
- Glass panels: use the `.glass` utility class
- Remove all `bg-gray-50`, `bg-white`, `bg-gray-100` backgrounds

### Border rules
- Default: `border-border`
- Emphasized: `border-border-strong`
- No colored borders (no `border-indigo-*`, `border-blue-*`)

### Animation rules (framer-motion)
- Wrap list items in `<motion.div>` with `initial={{ opacity: 0, y: 8 }}`
  and `animate={{ opacity: 1, y: 0 }}` with `transition={{ duration: 0.2 }}`
- Add `whileHover={{ scale: 1.01 }}` to clickable cards
- Add `whileTap={{ scale: 0.98 }}` to buttons
- Stagger children: use `transition={{ delay: index * 0.05 }}`
- Spring config for interactive elements:
  `transition={{ type: "spring", stiffness: 400, damping: 30 }}`

### Button rules
- Primary: `bg-primary text-primary-foreground rounded-xl px-4 py-2.5 text-sm
  font-medium transition-colors hover:opacity-90 active:scale-95`
- Secondary: `bg-background-secondary text-foreground border border-border
  rounded-xl px-4 py-2.5 text-sm font-medium hover:bg-background-tertiary`
- Ghost: `text-foreground-muted hover:text-foreground hover:bg-background-secondary
  rounded-xl px-3 py-2 text-sm transition-colors`
- Destructive: `bg-danger-bg text-danger border border-danger/20 rounded-xl
  px-4 py-2.5 text-sm font-medium`
- All buttons: `cursor-pointer select-none`

### Input rules
- `bg-background-secondary border border-border rounded-xl px-4 py-3 text-sm
  text-foreground placeholder:text-foreground-subtle outline-none
  focus:border-border-strong focus:ring-2 focus:ring-foreground/10
  transition-all duration-150`

### RTL rules
- Replace `ml-*` with `ms-*` (margin-inline-start)
- Replace `mr-*` with `me-*` (margin-inline-end)
- Replace `pl-*` with `ps-*` (padding-inline-start)
- Replace `pr-*` with `pe-*` (padding-inline-end)
- Replace `left-*` with `start-*` where logical
- Replace `right-*` with `end-*` where logical
- Replace `text-left` with `text-start`
- Replace `text-right` with `text-end`
- For flex rows with icons: use `gap-*` instead of margin on the icon
- Do NOT change: absolute positioning in overlay/tooltip/popover components
  where direction doesn't matter (e.g. centered loaders, full-cover overlays)

### Skeleton rules
Replace all `bg-gray-200` / `bg-gray-200/40` skeleton placeholders with
the `.skeleton` CSS class defined in globals.css.
